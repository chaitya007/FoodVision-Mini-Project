# 🍕🥩🍣 FoodVision Mini — Image Classification with PyTorch

FoodVision Mini is a computer vision project that classifies images of pizza, steak, and sushi using PyTorch.

The project covers the full workflow of training an image classifier — from data preparation and augmentation to building a CNN model and applying transfer learning for better accuracy. It also includes basic experiment tracking with TensorBoard to keep track of model performance and compare results.

The aim of this project is to build, train, and test a model that can correctly identify images of pizza, steak, and sushi.
Different models and training setups were tried out to improve performance and see how changes in the architecture and hyperparameters affected the results.
